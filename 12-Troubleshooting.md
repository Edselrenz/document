# 12 — Troubleshooting Manual

Use this diagnostic reference to resolve common issues across the Frontend, Desktop Client, Backend, Database, Cloudflare Worker, Authentication, and Build/Release pipelines.

| Area | Problem | Possible Cause | How to Diagnose | Solution | Relevant Files |
|---|---|---|---|---|---|
| **Backend / Startup** | FastAPI refuses to boot with `ValueError: jwt_secret_key must be explicitly configured` | `APP_ENV` is not `"development"` while `JWT_SECRET_KEY` is blank, `< 32` chars, or a known placeholder. | Inspect Uvicorn stderr traceback from `Settings.validate_secrets()`. | Generate a 64-char hex secret (`openssl rand -hex 32`) and set `JWT_SECRET_KEY` in `.env` or container environment. | `backend/app/core/config.py`, `.env.example` |
| **Database** | Backend silently writes to `nueva_ecija_travel.db` instead of PostgreSQL | PostgreSQL on `127.0.0.1:5432` was unreachable within `connect_timeout=2`. | Check Uvicorn startup logs for `"Configured database ... connection failed ... Falling back to canonical SQLite"`. | Start Docker Desktop and run `docker compose up -d`, verify `pg_isready`, then restart Uvicorn. | `backend/app/core/database.py`, `docker-compose.yml` |
| **Database** | `alembic upgrade head` fails with duplicate column or connection error | Schema drift between `ensure_user_profile_columns()` and migrations, or wrong `DATABASE_URL`. | Run `cd backend && alembic current` and verify `.env` `DATABASE_URL`. | Inspect `alembic_version` table; migration `0004` checks `existing_cols` safely, while earlier tables require a clean DB or `alembic stamp`. | `backend/alembic/env.py`, `backend/alembic/versions/` |
| **API / Proxy** | Web/Mobile shows `"Host laptop backend offline"` (`HTTP 502`) | `start_server.bat` is not running, or Cloudflare Tunnel / ngrok URL expired without syncing to `TUNNEL_KV`. | `curl https://ne-itinerary-api.<subd>.workers.dev/__status` and check `active_tunnels.updatedAt`. | Run `start_server.bat` with valid `WORKER_SYNC_URL` and `WORKER_SYNC_KEY` in `.env`; verify `POST /__sync_tunnel` returns `200`. | `cloudflare-worker/worker.js`, `scripts/start_server.ps1` |
| **API / Auth** | `401 Unauthorized` loop or unexpected logout | Access token expired (`30m`) AND refresh token expired (`7d`) or missing; or `JWT_SECRET_KEY` changed between restarts. | Inspect Network tab for `POST /api/v1/auth/refresh` response status. | Re-authenticate; ensure `JWT_SECRET_KEY` stays persistent across backend restarts. | `Project/src/app/core/interceptors/auth.interceptor.ts`, `backend/app/api/v1/auth.py` |
| **API / Auth** | `429 Too Many Requests` during testing or behind proxy | Hit SlowAPI limit (`30/min` login/register, `10/min` refresh, `5/min` Google OAuth, `120/min` global) or proxy IP not forwarding `CF-Connecting-IP`. | Check response status `429` and verify socket host + headers. | Wait 60 seconds; ensure reverse proxy connects via loopback (`127.0.0.1`) so `get_client_ip()` reads `CF-Connecting-IP`. | `backend/app/core/limiter.py`, `backend/app/api/v1/auth.py` |
| **Frontend / CORS** | Browser blocks API calls with CORS error | Request `Origin` is not in `CORS_ORIGINS` / `CORS_ORIGIN_REGEX` (backend) or `ALLOWED_ORIGINS` (Cloudflare Worker). | Inspect browser DevTools Console and `OPTIONS` preflight response headers. | Add the exact origin to `.env` `CORS_ORIGINS` and `cloudflare-worker/worker.js` `ALLOWED_ORIGINS`, then redeploy/restart. | `backend/app/core/config.py`, `cloudflare-worker/worker.js` |
| **Frontend / Routing** | Custom API URL set in `localStorage` gets cleared automatically | Hostname is not in `isTrustedApiHostname()` allowlist. | Check DevTools Console for `"[Security] Untrusted custom API hostname rejected"`. | Use a trusted domain (`localhost`, `127.0.0.1`, `*.workers.dev`, `*.trycloudflare.com`, `*.ngrok-free.dev`, `*.onrender.com`, `*.koyeb.app`) or update the allowlist. | `Project/src/environments/environment.ts`, `environment.prod.ts` |
| **Frontend / UI** | UI fails to update after async HTTP response or timer | Angular 22 runs with `provideZonelessChangeDetection()`. | Data updates in component state, but template stays stale until next click. | Inject `ChangeDetectorRef` and call `this.cdr.detectChanges()` (or use Angular Signals / `async` pipe). | `Project/src/main.ts`, affected `*.page.ts` |
| **Frontend / Map** | `L.markerClusterGroup is not a function` | Leaflet global `window.L` overwritten after plugin import. | Inspect DevTools Console on `/#/tabs/map`. | Verify `window.L` property guard in `Project/src/main.ts` is intact and `leaflet.markercluster` is imported before map init. | `Project/src/main.ts`, `Project/src/app/tabs/map/map.page.ts` |
| **Itinerary / Routes** | Routes return straight lines (`source: "haversine_direct"`) | `GOOGLE_MAPS_API_KEY` is unset AND public OSRM timed out (`3.0s`) or is unreachable. | Inspect `source` field in `POST /api/v1/itineraries/compute-day-route` response and backend logs. | Expected graceful fallback; set `GOOGLE_MAPS_API_KEY` in `.env` for Google Routes v2 or check outbound internet access to `router.project-osrm.org`. | `backend/app/services/google_maps_service.py` |
| **Itinerary / Dates** | Trip dates shift by 1 day in UI | Direct `new Date("YYYY-MM-DD")` parses as UTC midnight instead of local midnight. | Compare stored `start_date` vs displayed date in UTC-negative or UTC+8 timezones. | Always use `parseLocalIsoDate()` and `toLocalIsoDate()` from `date.utils.ts`. | `Project/src/app/core/utils/date.utils.ts` |
| **Desktop Client** | Standalone `.exe` fails to open Flet window or locate `osm_places.json` | Missing bundled `flet/` runtime or `_MEIPASS` path mismatch. | Run `dist\NuevaEcijaTravel\NuevaEcijaTravel.exe` from PowerShell to inspect stderr. | Re-run `python scripts/build_standalone_exe.py` after verifying `flet_desktop.ensure_client_cached()`. | `desktop_client/main.py`, `desktop_client/config/settings.py`, `scripts/build_standalone_exe.py` |
| **Android Build** | `./gradlew assembleDebug` fails with Java bytecode / unsupported class version | Capacitor 8 Gradle requires **JDK 21**. | Run `java -version` and `echo $JAVA_HOME`. | Install Temurin JDK 21 or run `scripts/build_android_apk.ps1` (auto-detects Android Studio JBR). | `scripts/build_android_apk.ps1`, `.github/workflows/release-builds.yml` |
